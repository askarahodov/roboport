# БоксРитм — визуальная приёмка UI

**Статус:** технические Playwright-снимки не заменяют решение владельца продукта о качестве дизайна. Независимая приёмка — #76, дизайн-гейт — #92. До их завершения не утверждать «дизайн одобрен».

## Регрессионные экраны

`apps/web/e2e/visual-audit.spec.ts` собирает 189 кандидатных PNG (21 маршрут/состояние × 390/1280/1440 px × Light/Dark/Auto). Включены автомобильная главная, вход, клиентские 401/403, пустые автомобили, запись и наряды, staff dashboard/403, календарь, приёмка, диагностика, сметы, QC, исполнение, закупки, приход, CRM, техническое закрытие, UI gallery и 404. Старый robot-каталог не входит в целевой UI. Сценарии с mock 401/403/empty не заменяют рабочий PG17/HTTPS lifecycle.

CI публикует `roboport-browser-evidence` из `apps/web/test-results/application/` и `apps/web/test-results/docs/`. Срок хранения 14 дней. Использовать PNG и manifest одного SHA; инструкция по воспроизведению — [SCREENSHOT_EVIDENCE](../guides/SCREENSHOT_EVIDENCE.md).

## Минимальный DoD

- Первый экран: визуальная иерархия, ценностное предложение, CTA, достаточный контраст и отсутствие обрезки.
- Вход и кабинет: понятные ошибки, отзыв прав, безопасное отображение только доступных автомобилей, записей, заказов и документов.
- Staff: меню и доступ по серверным ролям; приёмка, диагностика, сметы, склад, QC, аудит. Синтетические 403/409 не разрешают реальных операций.
- 390/1280/1440 px: без root overflow, с понятной навигацией с клавиатуры и видимым фокусом.
- Автоматический аудит проверяет вычисленное accessible name видимых действий и полей в main штатным matcher Playwright; placeholder сам по себе не заменяет label. Неверные/пустые ссылки aria-labelledby и aria-hidden-only текст не должны давать ложный PASS. Проверяются также положительные контрольные примеры.
- Контраст, порядок Tab, размеры целей и полные пользовательские сценарии проверяются отдельно вручную по WCAG AA; автоматическое имя и PNG не доказывают соответствие всему стандарту.
- Владелец фиксирует PASS/FAIL по каждому экрану на точном SHA и run ID, с примером неприемлемого элемента. Дефекты связываются с #92/#76.

**Пока нет утверждённых golden PNG и согласованного порога pixel-diff.** Не обновлять эталон автоматически при падении теста. До независимой приёмки снимки остаются кандидатами; production gate #119 не меняется.
