# ROBOport — предварительный брендбук для разработки

**Статус:** рабочий дизайнерский handoff, но не товарный знак/разрешение на печать и публичное использование. Название ROBOport остаётся рабочим.

## 1. Позиционирование

Независимый мультибрендовый сервис домашней робототехники. Характер: спокойный, инженерный, доброжелательный, точный в обещаниях. Не писать «официальный сервис Dreame/Roborock/Xiaomi» без подтверждённой авторизации. Не обещать обслуживание всех моделей.

## 2. Логотип

**Выбран оригинальный C Industrial Lab — угловая буква R из трёх SVG-path.** Канонические исходники в `design/brand/symbol-light.svg` и `symbol-dark.svg`, горизонтальные wordmark — там же. **Не заменять знаком A (гексагон)**. Не менять геометрию контуров, отрицательное пространство и пропорции, не растягивать и не добавлять случайные тени/обводки.

Светлый, тёмный и монохромные варианты; предварительное защитное поле ≥0.3 высоты знака, для wordmark — высота буквы «O». Предварительный минимум знака 32px на экране и 12мм в печати (не окончательно). Для коммерческой вывески требуются цветопроба и legal/IP review.

## 3. Фирменные цвета и темы

| Роль | Light | Dark |
|---|---|---|
| canvas | `#F3F8FA` | `#071820` |
| surface | `#FFFFFF` | `#102731` |
| text | `#102736` | `#F3FAFC` |
| декоративный акцент | `#008C84` | `#38D9C9` |
| кнопка основная | `#006D67` | `#11766F` |
| маленький акцентный текст | `#006D67` | `#38D9C9` |

Источник — `design/tokens/theme.json` и `theme.css`. Light/Dark/Auto равноправны; Auto использует настройку ОС. Изменение темы **не влияет на авторизацию**. Safety hold/QC FAIL/error обозначаются и текстом, и иконкой, не только цветом. Проверить контраст реальных сочетаний WCAG 2.2 AA, включая focus/hover/disabled.

## 4. Типографика и графические элементы

Доступные системные sans-шрифты с поддержкой кириллицы; Inter/Manrope — кандидаты при проверке лицензий. Размер основного текста ≈16px; адаптивные заголовки и видимый focus; иконки с согласованной толщиной штриха, доступными текстовыми метками. Не добавлять чужие OEM-логотипы/фотографии без права.

## 5. Применение в продуктах

- Публичный сайт: главная, каталог, карточка модели, доступность сервиса и форма обращения после feature gate.
- Личный кабинет: шесть разделов и состояния loading/empty/401/403/404/409/revoked, версии смет, документы и уведомления.
- CRM: очередь, приёмка, диагностика/Safety hold, сметы, склад, QC/выдача, аудит.
- Печатные носители (только черновик): вывеска, зона приёмки, форма/бейдж, визитка, квитанция, заказ-наряд, акт, QR-этикетка и упаковка.

## 6. Примеры тона

«Проверяем возможность обслуживания» вместо «Ремонтируем всё». «Смета версии 2 ожидает подтверждения» вместо «Цена фиксирована навсегда». «Работы приостановлены для проверки безопасности» вместо одного красного ярлыка. Сообщения 403/404 не подтверждают существование чужой заявки.

## 7. Критерии передачи разработчикам

Editable SVG, light/dark/mono, JSON/CSS tokens, базовые состояния компонентов, мобильный режим 390px, измеримый контраст, тесты оригинальной геометрии C и реальные скриншоты. **Не выполнено:** полиграфические мастер-файлы, права на имя/знак, полнота UX-сценариев, независимый WCAG и внешний запуск. Задача дизайнерского handoff — GitHub #14.
