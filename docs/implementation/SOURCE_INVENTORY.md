# Происхождение материалов

- Google Drive `robo` — историческая рабочая документация, старые прототипы, финансовые и сервисные гипотезы. Не зеркалировать автоматически личные или внутренние данные в публичный GitHub.
- `TECHNICAL_SPEC.md` — каноническая русскоязычная разработческая спецификация, пересмотр через PR/ADR.
- `contracts/openapi.yaml` — 42 **проектных** операции и 56 схем; на текущем backend реализованы только health/meta и три синтетические read-only операции каталога. Нельзя приписывать реализации весь проектный контракт.
- `db/legacy_drafts/001–006` — неподтверждённые PostgreSQL черновики, НЕ миграционная история.
- `design/` — оригинальный логотип C, темы A Light/Dark/Auto и автономный demo с синтетическими данными.
- `docs/implementation/WORK_BREAKDOWN.md` — соответствие реальным GitHub Issue, не старая конфликтующая нумерация RP.

Все значения readiness/availability/числа тестов должны подтверждаться конкретными командами и ссылками на GitHub CI. Текущее отсутствие CI/DB считается открытым препятствием, а не доказательством зелёного результата.
