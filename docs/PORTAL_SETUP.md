# Браузерная база знаний Docsify — локальный запуск

**Статус:** dev-only. [Задача #132](https://github.com/askarahodov/roboport/issues/132). Стек: **Docsify 5.0.0**, CSS core + search plugin с точной версией через jsDelivr. Markdown-содержимое остаётся в существующих файлах `docs/**/*.md`, дублирования в HTML нет.

## Linux / macOS / Windows CMD

В корне репозитория (не внутри `docs`) запустите:

```bash
python -m http.server 3080 --bind 127.0.0.1
```

В **Windows CMD** эта же команда работает при доступном `python`; если команда `python` отсутствует, можно использовать `py -3 -m http.server 3080 --bind 127.0.0.1`.

Откройте [локальную базу знаний](http://127.0.0.1:3080/docs/). Не запускайте сервер с `--bind 0.0.0.0` в небезопасной сети.

**Важно:** Docsify JS/CSS подключаются из зафиксированной версии CDN. Для первоначального открытия необходим доступ к `cdn.jsdelivr.net`. Это не offline/bundled распространение и не разрешение публиковать документацию; будущая автономная упаковка допускает self-host assets после отдельной проверки лицензии/целостности.

## Автоматические проверки

```bash
python scripts/check_docs_links.py
cd apps/web
npm ci
npm run test:docs:e2e
```

Для второго шага нужен установленный Playwright Chromium: `npx playwright install chromium`. CI `browser-e2e` использует тот же Chromium и запускает локальный HTTP-сервер для реальной навигации по страницам в браузере (не screenshot mock).

## Навигация и обновление

- `docs/README.md` — стартовая страница.
- `docs/_sidebar.md` — единая навигация (не создавать ссылок на несуществующие Markdown).
- `docs/guides/*.md` — пользовательские руководства с фактическим `current` или `planned`.
- `docs/auto/*.md` — документация автомобильного домена.
- `docs/theme.css` — локальная адаптивная тема.
- `docs/index.html` — configuration + закреплённые CDN зависимости.

Когда появляется новый функциональный экран, обновить соответствующий `docs/guides/*.md`, статус и ссылки в том же PR. Проверки не заменяют ручное ролевое QA и проверки актуальности содержания.

Не выдавать этот dev-портал за публичный сайт Airmatik Pro Service. Секреты и ПДн никогда не добавляются в Markdown.
