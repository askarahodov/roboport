# База знаний Airmatik Pro Service

> **Статус: внутренний автомобильный портал `current-dev` / `planned`.**
> **Бренд-переход (09.11.2026):** утверждённое целевое название — **«БоксРитм»** (Auto Digital, #110). В заголовках и текущем dev UI ещё встречается **Airmatik Pro Service**: это действующее на данном SHA, но **устаревшее** название, а не утверждённый бренд нового продукта. Сквозной ребрендинг интерфейса, API-метаданных и Docsify должен быть проверен вместе по #110/#121; менять только текст справки и выдавать его за готовый ребрендинг нельзя. Публичный запуск не разрешён (#119).
> Проверка актуального HTTP runtime: 09.11.2026. Это **не публичный запуск**;
> в рабочем контуре запрещены реальные VIN, ПДн, платежи и физическая
> выдача автомобиля. Коды, SQL и URL приведены для тестового synthetic стенда.

Здесь собраны **реальные на сегодня синтетические** сценарии сотрудников СТО
и клиента — без подмены планов кнопками. Автомобильные функции не являются
переименованием робототехнических заявок. Вопросы авторизации, согласия и
подтверждения заказа решаются сервером, а не знанием UUID.

## С чего начать

**[Навигатор задач](guides/ROLE_NAVIGATOR.md)** — найти экран, роль, тест и безопасное действие при отказе. **[Быстрый старт по ролям](guides/QUICK_START.md)** — подготовка dev-контура,
вход, одно сквозное прохождение заказ-наряда, сообщения 401/403/409 и
границы релиза. **[Матрица ролей и доступов](guides/ACCESS_AND_TEST_MATRIX.md)**
связывает экран, действующую роль, API и тест; **[FAQ](guides/FAQ.md)**
объясняет сбои, а **[руководство по скриншотам](guides/SCREENSHOT_EVIDENCE.md)**
показывает, как получить безопасные воспроизводимые PNG/QA-протокол.

## Архив и техническая документация

В рабочем ASGI зарегистрированы автомобильные dev-маршруты; прежние robot HTTP-маршруты исключены из live runtime и изолированы в тестовой регрессии. Архивные robot SQL-данные и draft OpenAPI сохраняются до отдельного контролируемого decommission #165 и разрешений #119. Полное удаление данных, боевой запуск и юридическая выдача не разрешены.
