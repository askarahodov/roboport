# База знаний Airmatik Pro Service

> **Статус: внутренний dev-портал.** Автомобильные функции создаются поэтапно. Инструкции со статусом **«Планируется»** не описывают доступные сегодня кнопки и операции. Реальные клиентские данные и секреты запрещены.

Это единая точка входа в документацию разработчиков, QA, сотрудников и будущих клиентов автосервиса.

## Что уже проверено

**Current (синтетический dev):** FastAPI, PostgreSQL 17, существующие проверки ролей, базовые данные автомобиля, закрытый сценарий подтверждения связи и отзыв доступа. [Сценарий подтверждения автомобиля для QA](auto/VEHICLE_OWNERSHIP.md).

**Legacy:** действующая робототехническая предметная область ROBOport, документация которой не является инструкцией нового автосервиса.

**Planned:** публичный сайт Airmatik, полноценная регистрация авто, онлайн-запись, заказ-наряды, склад автозапчастей, клиентский кабинет, мобильное приложение.

## Правила обновления

Любое изменение функции требует одновременно обновить затронутые технические и пользовательские руководства. [Политика документации](DOCUMENTATION_POLICY.md), [аудит актуальности](auto/DOCUMENTATION_AUDIT.md). Разделы доступны через навигацию слева; в мобильной версии используйте меню.

Рабочие задачи в [GitHub epic #107](https://github.com/askarahodov/roboport/issues/107) и [docs epic #121](https://github.com/askarahodov/roboport/issues/121). **Это не публичный сайт автосервиса.**
