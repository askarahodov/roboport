# База знаний Airmatik Pro Service — роли

> **Статус: planned / подготовка.** Это **карта будущих руководств**, не документация готового автомобильного продукта. Текущее приложение продолжает обслуживать тестовую робототехническую предметную область. Существует закрытый синтетический read-only endpoint просмотра подтверждённых автомобилей, однако **публичной страницы «Мои автомобили» пока нет**. Не вводите реальные клиентские данные.

Инструкции создаются **только после появления соответствующего рабочего сценария**; каждую инструкцию сверяют с конкретным UI, backend ACL и E2E.

| Роль | Сценарии будущего руководства | Зависимости |
|---|---|---|
| Администратор | организация/филиалы, сотрудники, роли, справочники, диагностика и безопасность | #112, #113, #119, #123 |
| Мастер-приёмщик | клиент/автомобиль, запись, приёмка, заказ-наряд, смета, выдача | #112–#114, #123 |
| Диагност/механик | назначенные работы, фото осмотра, диагностика, запчасти, нормочасы, QC | #114, #123 |
| Кладовщик/закупщик | OEM-кроссы, применяемость, резерв, закупка, возвраты | #111, #115, #123 |
| Руководитель | загрузка постов, отчётность, качество и права | #113, #116, #123 |
| Бухгалтер/кассир | счета, оплаты, чеки, возвраты, сверка | #116, #123 |
| Клиент | вход, автомобили, запись, статус, согласование, документы, настройки | #112–#114, #117, #124 |
| Клиент iOS/Android | мобильный вход, записи, уведомления, документы, приватность | #118, #124 |

## Как должна выглядеть инструкция

**Роль → Предусловия → Экран → Шаги → Ожидаемый результат → Ошибки/действия → Права → Проверено на версии.** Названия кнопок и ссылок должны совпадать с текущим интерфейсом, примеры — только синтетические.

Техническая документация находится в [общем индексе](../INDEX.md); правила актуальности — [DOCUMENTATION_POLICY.md](../DOCUMENTATION_POLICY.md). За разработку пользовательской базы знаний отвечают [#123](https://github.com/askarahodov/roboport/issues/123) и [#124](https://github.com/askarahodov/roboport/issues/124), публикация — [#125](https://github.com/askarahodov/roboport/issues/125).
