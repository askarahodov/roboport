# Клиент автосервиса

> **Статус: частично current в синтетическом dev, остальное planned.** Только просмотр подтверждённых автомобилей через тестовую страницу реализован; запись, заказ-наряды и production-вход запланированы. Реальные данные не вводить.

## Для кого

Автовладелец. Доступ к каждой операции должен проверяться по активной сессии, роли и конкретному объекту.

## Какие задачи появятся

Вход, мои автомобили, запись, перенос времени, статус ремонта, просмотр и согласование версии сметы, документы и история.

## Что реально доступно сейчас

**В dev-стенде существует только экран просмотра «Автомобили (dev)»** по пути `/account/vehicles`. Самостоятельная регистрация или привязка автомобиля клиентом, открытое производство и мобильный интерфейс пока отсутствуют. Закрытый dev API возвращает только подтверждённые связи. [Описание QA-сценария](../auto/VEHICLE_OWNERSHIP.md).

## Дальнейшая документация

По мере ввода новых автомобильных операций будут добавляться проверяемые скриншоты, точные действия для приёмщика и клиента, сообщения 401/403/404/409 и версия сборки. Текущая инструкция по просмотру доступна ниже.

**Зависимости:** #112, #113, #114, #117, #124. [Текущая карта продукта](../auto/PRODUCT.md) · [правила актуальности](../DOCUMENTATION_POLICY.md) · [индекс ролей](INDEX.md).

**До релиза:** запрещены настоящие VIN, телефоны, клиентские документы и платёжные данные в dev-стенде.

## Просмотр тестовых автомобилей — current (только dev)

1. В тестовом контуре открыть `/account/login` и авторизоваться тестовой учётной записью. Для работы с приватным API необходим HTTPS loopback, включённый синтетический backend и тестовый PostgreSQL 17; открывать через обычный HTTP нельзя.
2. Открыть «Личный кабинет» → «Автомобили (dev)». Путь: `/account/vehicles`. Раздел появляется только после успешной проверки серверной cookie-сессии.
3. Дождаться загрузки. Если клиент имеет подтверждённую связь, появятся марка, модель, комплектация (если указана), год выпуска и последние 4 символа VIN. **Полный VIN не показывается.**
4. Если связи пока ожидают независимую проверку, экран показывает «Подтверждённых автомобилей пока нет». Это не ошибка — знание VIN и создание pending-связи ещё не дают доступ.
5. При сообщении о запрете доступа проверить тестовую сессию, роль CLIENT и разрешённый dev API; при ошибке сети нажать «Обновить автомобили». После отзыва прав повторный запрос должен скрыть автомобиль.

**Ограничения:** создание/удаление машины, загрузка документов, подтверждение по VIN и просмотр старых нарядов на этой странице не реализованы. Скриншоты и тесты использовать только с синтетическими марками/VIN. Реальный клиентский интерфейс и публичный контракт — ещё запланированы по #131 и #124.
