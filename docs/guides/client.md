# Клиент автосервиса

> **Статус: planned / инструкция ещё не применяется.** Сведения ниже — проектный план, а не перечень работающих кнопок. В dev используйте только синтетические данные.

## Для кого

Автовладелец. Доступ к каждой операции должен проверяться по активной сессии, роли и конкретному объекту.

## Какие задачи появятся

Вход, мои автомобили, запись, перенос времени, статус ремонта, просмотр и согласование версии сметы, документы и история.

## Что реально доступно сейчас

Страница «Мои автомобили» и самостоятельная привязка авто отсутствуют. В закрытом dev API существуют просмотр только подтверждённых связей и предъявление одноразового доказательства. [Описание QA-сценария](../auto/VEHICLE_OWNERSHIP.md).

## Подготовка пользовательской инструкции

После реализации соответствующего экрана будут добавлены точный путь по меню, названия кнопок, необходимые права, пошаговые действия, результат операции, диагностика типичных ошибок (401/403/404/409), безопасные скриншоты и версия проверки.

**Зависимости:** #112, #113, #114, #117, #124. [Текущая карта продукта](../auto/PRODUCT.md) · [правила актуальности](../DOCUMENTATION_POLICY.md) · [индекс ролей](INDEX.md).

**До релиза:** запрещены настоящие VIN, телефоны, клиентские документы и платёжные данные в dev-стенде.
