# Администратор

> **Статус: planned / инструкция ещё не применяется.** Сведения ниже — проектный план, а не перечень работающих кнопок. В dev используйте только синтетические данные.

## Для кого

Администратор сервиса. Доступ к каждой операции должен проверяться по активной сессии, роли и конкретному объекту.

## Какие задачи появятся

Подготовка организации и филиалов, справочников, рабочих постов; создание и отзыв пользователей/ролей; просмотр журналов, настройки интеграций и защита персональных данных.

## Что реально доступно сейчас

Пока отсутствует публичный интерфейс настройки организации и назначения сотрудников. В синтетических тестах роли хранятся в PostgreSQL и должны быть изолированы от реальных данных.

## Подготовка пользовательской инструкции

После реализации соответствующего экрана будут добавлены точный путь по меню, названия кнопок, необходимые права, пошаговые действия, результат операции, диагностика типичных ошибок (401/403/404/409), безопасные скриншоты и версия проверки.
