Ролевые инструкции: [приёмщик](../guides/intake.md), [клиент](../guides/client.md).

Комплекс выбирается вместо отдельных услуг и материалов. Для него обязательны INTAKE,
MANAGER, WAREHOUSE и действующие полномочия ESTIMATE. Стоимость не показывается
в справочнике записи, списание не производится до соответствующего этапа наряда.
Сотрудник в тестовом справочнике обозначается UUID, без персональных данных.
Кандидаты окон не гарантируют бронь; фактический резерв атомарен.
Запись без услуг при подборе переноса сохраняет исходную длительность, округлённую
вверх до минуты. Старые эндпоинты сохранены для совместимости.

**Ограничения и внешние условия:** публичный виджет с реальным CAPTCHA/согласиями,
внешние callback/доставка (#442), мобильная авторизация (#117), security/legal,
независимая визуальная приёмка и production release (#119) не считаются выполненными.
Закрытые dev-маршруты не публикуются. Не закрывать исходные Issues до подтверждения
полного исходного DoD; не создавать подзадачи для каждого исправления.
